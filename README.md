# ESP32-Smart-Distance-Monitoring-Using-KiwisIoT
ESP8266 Smart Distance Monitoring using NodeMCU and an HC-SR04 ultrasonic sensor with real-time distance measurement and data visualization through the KiwisIoT platform.
ESP8266 Smart Distance Monitoring Using KiwisIoT
About the Project
The ESP8266 Smart Distance Monitoring is an IoT-based project designed to measure and monitor distances in real time using an ultrasonic sensor.

Using an ESP8266 NodeMCU microcontroller and an HC-SR04 ultrasonic sensor, the system measures the distance between the sensor and an object. The collected distance data is transmitted to the KiwisIoT platform through Wi-Fi, allowing users to monitor distance readings remotely through an online dashboard.

By integrating KiwisIoT, this project demonstrates a simple and effective approach to IoT-based distance measurement, real-time data visualization, and remote monitoring.
